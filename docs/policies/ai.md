# Use of AI tools

## In this project

Most of the code, tests and documentation in this repository are written with AI coding tools,
and reviewed by the maintainer before they are merged. Saying so is the first half of the
policy. The second half is what makes the first acceptable:

- Every behaviour this library claims, in the README, the changelog or a docstring, is backed by
  a test in `tests/` or by a command you can run yourself. A claim without one is a bug; please
  report it.
- Every change passes the same gates in CI, whoever or whatever wrote it: mypy in strict mode,
  ruff, and the test suite on every Python version in the CI matrix.

## For contributors

Contributions are welcome whatever tools you used to write them, and they are reviewed on the
same evidence. Two requests:

- Say in the pull request if a substantial part was generated by an AI tool.
- Run what you submit. A pull request whose tests were never run, or an issue describing
  behaviour nobody reproduced, costs more to review than it saves.
